# 🎯 Calibration

Offsets are applied before readings are stored.

## Reference station

Readings were compared with a reference station 2 km away over two weeks. The temperature offset is the mean difference:

$$
\Delta T = \frac{1}{n}\sum_{i=1}^{n} \left(T_i^{\text{ref}} - T_i\right)
$$

| Reading | Offset |
| --- | ---: |
| Temperature | −0.4 °C |
| Humidity | +2 % |
| Wind speed | ×1.08 |
